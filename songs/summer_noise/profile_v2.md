# 楽曲言語化プロファイル v2

プロデューサー／音楽理論家の視点から、計測値のデータと実際の音響空間・聴感を統合し、この楽曲を高解像度に言語化・解剖します。

---

### 1. 一言サマリ
**哀愁のネオソウル波形と浮遊する日本語歌唱が織りなす、チル・Lo-Fi R&B。**

---

### 2. スタイル座標
- **ジャンル系譜**: Neo-Soul / Lo-Fi R&B / Japanese Alternative R&B
- **年代感**: 2020年代前半（現代的なストリーミング・チルサウンドの標準）
- **シーン**: SIRUP、iri、FKJ、Tom Misch、SZAなどを好むリスナーに向けた、ベッドルーム〜ナイトドライブ・プレイリスト直結のサウンドデザイン。

---

### 3. 和声の設計
主要キーは **A# Major（B♭ Major）**。ダイアトニック率97%という数値が示す通り、極めて自然で耳馴染みの良いトーンスケールで構成されています。

#### 【メイン・コード進行のディグリー解釈】
基本フォーマット：**I → vi → IV → ii → V**
（A# → Gm → D# → Cm → F）

- **I（A# / トニック）**: 楽曲の基調となる安定感。
- **vi（Gm / 代理トニック）**: トニックからスッと影を落とすエモーショナルな斜陽感。
- **IV → ii（D# → Cm / サブドミナント群）**: 切なさを増幅させながら、ドミナントへ向かって徐々にグラデーションをつけるステップ。
- **V（F / ドミナント）**: 定番の強進行で再びトニック（I）へと滑らかに接続し、循環性の高いメロウな中毒性を生む。

#### 【テンションと質感の聴感観察】
三和音検出（A#, Gm...）の裏で、実際には **Imaj7** や **vi7**、**IVmaj7**、**ii7**、さらには9thテンションを含んだボイシングが多用されています。特にウクレレ／エレピ風のコード刻みにおいて、トップノートに9thや7thのテンションを残したままコードチェンジが行われるため、ジャジーで都会的なエッジと切ない余韻が空間に漂っています。

#### 【ブリッジセクション（88〜95s付近）の特筆点】
`Cm (ii) → D (III) → A# (I) → C (II) → D# (IV)`
ここでの **D（III: ドミナント7thのニュアンス）** や **C（II: セカンダリー・ドミナント）** の挿入は、ノンダイアトニックなスパイスとして機能。一時的にトナリティを揺らし、楽曲全体の中で最もエモーショナルなカタルシス（サビ〜ブリッジの盛り上がり）を演出しています。

### 4. サウンドパレット
- **メインボーカル [確信度：高]**: ウィスパー混じりのエアリーな日本語女性ボーカル。ダブル（重層化）や空間系エフェクト（ディレイ/リバーブ）により、存在感を出しつつもサウンドの中に深く溶け込ませている。
- **リードコード楽器（撥弦音） [確信度：高]**: ウクレレまたはナイロン弦ギターの質感を模した、高域が丸くウォームなコードカッティング。
- **エレピ / シンセパッド [確信度：高]**: Rhodes特有のコシのあるアタックと、ローファイ・ウォブル（微妙なピッチの揺れ）を伴う広大なパッド。
- **ベース [確信度：高]**: サブベース領域をどっしりと支えるシンセベース。ミッドハイの余計な帯域を削り、ボトムのグルーヴに集中。
- **ドラム・パーカッション [確信度：高]**: 808調の太いキック、タイトで少しディレイの効いたスネア/リムショッ ト、そして16分で細かく打たれるローファイなハイハット。

---

### 5. リズムとグルーヴ
- **BPM解釈**: 検出値 `129.2` ですが、聴感上は完全な **ハーフタイム（BPM 64.6）** のR&B/スローポップスとして機能しています。
- **ビートの性格**: ジャストのグリッドから微小に遅らせた（レイドバックした）ハーフタイム・スネアと、走るハイハットの対比。
- **グルーヴの支配者**: **「キックの裏のタメ」と「コード楽器のカッティングのバックビート」**。グリッド値 `129.2` に対し、オンセット密度（オンスの発生密度）が1.6〜1.8と一定を保っており、縦のラインを無理に崩さず、チルな気持ちよさを均一に提供する設計になっています。

### 6. 構成のドラマ
計測値の `energy_pct`（エネルギー）と `brightness_hz`（明るさ/高域の開き）の変化が、構成のドラマを見事に物語っています。

- **0.1-33.5s (Aメロ〜Bメロ) [Energy: 85% / Brightness: 1457Hz]**
  ローファイなフィルター感で抑えめにスタート。歌とコードの距離感が近く、密室感のあるイントロダクション。
- **33.5-51.4s (サビ 1) [Energy: 90-95% / Brightness: 1524-1637Hz]**
  Brightnessが一気に1637Hzまで上昇。ハイハットの高域やボーカルのエア感・ハモリが開放され、一気に視界が開ける。
- **56.9-95.8s (2番〜展開部) [Energy: 85% / Brightness: 1351Hz]**
  一度Brightnessを1351Hzまで意図的に落とし、落ち着いたAメロに戻すことで展開の「溜め」を作る。
- **95.8-99.0s (ブリッジの頂点) [Energy: 100% / Brightness: 1415Hz]**
  楽曲全体のピーク。エネルギー計測値100%を記録。コード展開のドラマ性と相まって最大の感情的エモーショナルに達する。
- **115.9-161.3s (アウトロ) [Energy: 82% / Brightness: 1389Hz]**
  余韻を残しながら徐々にエネルギーを減衰させ、心地よい脱力感とともに着地。

### 7. 動きの源泉
この曲の推進力（ドライブ感）は、**「タイトに刻まれる16分ハイハットの粒子感」と「サビで展開されるサマーライ〜♪のメロディのリフレイン」** の補完関係に潜んでいます。低層（ベース）が非常に重くゆったり動くのに対し、高層（ハイハット・ボーカルのアタック）が細かく動くことで、心地よい「揺らぎ」の推進力が生まれています。

   - *類似要素*: 循環コードに乗せる日本語ウィスパーR&B歌唱のフローと、都会的なチル感。

   - *類似要素*: 低音のグルーヴ感と、哀愁を帯びたポップネスの融合。

### 9. この曲だけの指紋
**「アコースティック（ウクレレ調）な手触りと、重厚な808系サブベースの極端なハイブリッド」**
ベッドルーム・ポップの持つ温かみのあるオーガニックなコード奏法と、クラブ・ミュージック譲りの低域のボトム感が矛盾なく同居しており、無菌室的でありながらエモーショナルな独自の空気感を作り出しています。

### 10. プロデューサーの視点（次の一手）
楽曲としてすでに非常に完成度が高いですが、プロダクションをワンランク上の「プロクオリティ」へ引き上げるための具体案を提案します。

1. **ボーカルの「子音（Transient）」の明瞭化とサチュレーション**
   - *提案*: ウィスパーの質感が魅力的な反面、中低域のトラックにボーカルの子音（特に「s」「k」「t」などの発音）が埋もれがちです。1.5kHz〜3kHz付近をフェアドチャイルド系や1176系の速いコンプでわずかに叩き、パラレル・サチュレーション（Tape/Tube）をほんの少し足すことで、囁き声のまま輪郭を前に出すことができます。
2. **ブリッジ（90-99s）におけるローエンドの展開補強**
   - *提案*: コード進行が `Cm → D → A# → C` と最もドラマチックに展開するセクション（95.8-99.0s）で、サブベースのラインをコードのルート追従だけでなく、オクターブ上のスライド移動やアプローチノートを加えることで、100%のエネルギーピークに対するダイナミクスを完璧に補強できます。
