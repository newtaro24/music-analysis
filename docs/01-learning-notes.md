# 音楽解析 学習ノート 01 — 基礎編

このプロジェクトで実際に使った概念だけを、使った順に記録する。

## 1. ピッチ抽出 (f0) と pYIN — analyze_memo.py
- **f0 (基本周波数)**: 「その瞬間に鳴っている音の高さ」。単旋律でしか安定して取れない
- **pYIN**: 波形の自己相関で周期を見つけるYIN法の確率版。「無声(声が鳴ってない)区間」の判定も同時にできるのが実用上重要
- **ノート化**: 連続f0曲線→音符に区切る処理は意外と職人芸。無声で切る/ピッチジャンプ(80セント)で切る/短すぎる断片は捨てる。音高は平均でなく**中央値**を使う(ビブラートに強い)

## 2. クロマグラム — analyze_mix.py
- 音源を12半音クラス(C, C#, ... B)の強度分布に潰したもの。オクターブ情報を捨てることで「和声的な内容」だけが残る
- ポリフォニック音源でキーやコードを扱う基本素材。ただしノイズ・パーカッションで濁る(summer_noiseでC#が妙に強く出たのはおそらくこれ)

## 3. キー推定と Krumhansl-Schmuckler プロファイル
- 「あるキーの曲で12音がどの重みで使われるか」の心理実験由来テンプレート。曲の音分布との相関が最大のキーを採用
- **学び(実戦から)**: summer_noiseで「解析=Cマイナー、本人=B♭」と割れた。ただしCドリアン(Cを中心にB♭メジャーの音セットで回る)なら両方正しい。**トニック(重心)とモード(音セット)は別の問題**で、テンプレート相関はこの2つを区別するのが苦手。エレクトロニック系はモード曖昧な曲が多く、実用ツールでは「候補+根拠」を出して人が確定させるUXが正解

## 4. テンポ推定・オンセット
- **オンセット強度**: 音の立ち上がり(アタック)の強さの時系列。ドラムが明確ならテンポ推定は安定、鼻歌だと不安定
- **ビートトラッキング**: オンセットの周期性からBPMとビート位置を推定。倍/半分テンポ(129 vs 64.5)の取り違えは宿命的な弱点

## 5. 帯域別エネルギーと「アレンジの言葉」への翻訳
- スペクトログラムを low(〜120Hz) / low-mid(〜500) / mid(〜2k) / high-mid(〜6k) / high に分けて時系列集計
- RMS(音量)、スペクトル重心(明るさ)、オンセット密度(手数)をセクション別に出すと「どのセクションが何で埋まっているか」が言葉にできる
- **学び(実戦から)**: 音量カーブの平坦さは何も語らない。「動きがどこに住んでいるか」(音量/音色/テクスチャ/ステレオ)を分けて測るのが本質。時間スケール別の自己相似性解析が次の課題

## 6. 構成(セクション)検出
- ビート同期したクロマ+MFCC(音色の特徴量)をクラスタリングし、「特徴が変わる場所」を境界とする
- v0は過剰分割気味(2小節の断片が出る)。SALAMI/Harmonixなど人手アノテーション付きデータセットで精度検証できる

## 7. アーキテクチャの学び
- **Spotify Audio Features APIは2024年に死んだ**。代替はEssentia(同系のOSS)、各種特徴量API
- **音声入力LLM(Gemini / Qwen3-Omni / Music Flamingo)が「感覚の記述」を担える時代**。数値(定規)と感覚(耳)を突き合わせるのが本プロジェクトの解析コア
- Qwen3-OmniはM5 Pro/48GBに載る規模(MoE 30B/アクティブ3B)だが、Macの音声入力ランタイムが未成熟(2026-08時点)。まずGemini無料枠で検証
- 30秒プレビューAPI(iTunes/Deezer, 認証不要)で任意アーティストの音色・ムード比較は可能。フル尺のアレンジ参照はCC音源(MTG-Jamendo/FMA)か手持ち音源で

## 8. コード認識: 手組み vs 学習済みモデル (実測)
- 手組みv0(3和音テンプレ): maj7系で部分集合誤爆(B♭M7→F)。v1(4和音+ベース加点)で54%
- **madmom(DeepChroma DNN + CRF復号): 同曲で実質100%**。DNNが「倍音の濁りからクロマを綺麗にする」部分を学習で解いているのが決定差
- 教訓: クロマの質がコード認識の上限を決める。テンプレート照合・ビタビ平滑化の原理は手組みで理解済み——その上で成熟タスクは既製モデルに任せる
- キー推定の正攻法も見えた: 音の分布(KS法)でなく、検出コード列のカデンツ(F:maj→B♭:majの解決)からトニックを決める
